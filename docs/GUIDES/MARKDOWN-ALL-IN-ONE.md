## Introduction

The **Markdown All in One** extension enhances your markdown editing experience with:

- **Auto-updating Table of Contents** - TOC stays in sync with headings
- **Keyboard Shortcuts** - Quick formatting with familiar shortcuts
- **Smart List Editing** - Intelligent indentation and renumbering
- **Table Auto-Formatting** - GFM tables align automatically
- **Task List Toggling** - Check/uncheck tasks with a keystroke
- **Math Rendering** - LaTeX-style math in preview
- **HTML Export** - Publish documentation as styled HTML

All features are **optional** - markdown generated by agents works without the extension installed.

## Installation

### Automatic (Recommended)

When you open a Syntek Dev Suite project in VS Code, you'll be prompted to install recommended extensions. Click **Install** to add Markdown All in One.

### Manual Installation

1. Open VS Code
2. Press `Ctrl+Shift+X` (Windows/Linux) or `Cmd+Shift+X` (macOS)
3. Search for "Markdown All in One"
4. Click **Install**

Or install via command line:

```bash
code --install-extension yzhang.markdown-all-in-one
```

### Verify Installation

After installation, open any `.md` file and:
1. Right-click in the editor
2. Look for "Markdown All in One" commands in the context menu

## Table of Contents Management

The Table of Contents feature is one of the most useful for documentation.

### Creating a TOC

1. Position your cursor where you want the TOC
2. Open Command Palette: `Ctrl+Shift+P` (Windows/Linux) or `Cmd+Shift+P` (macOS)
3. Type "Create Table of Contents"
4. Press Enter

The extension generates a TOC based on all headings in the document.

### Auto-Update on Save

The workspace is configured to **auto-update the TOC when you save**. This means:

- Add a new heading → TOC updates on save
- Rename a heading → TOC link text updates on save
- Delete a heading → TOC entry removed on save

No manual intervention needed.

### Excluding Headings

To exclude a heading from the TOC, add `<!-- omit in toc -->` after it:

```markdown
## Internal Notes <!-- omit in toc -->

This section won't appear in the TOC.
```

### TOC Settings

The workspace is configured with these TOC settings:

| Setting                    | Value    | Effect                                 |
| -------------------------- | -------- | -------------------------------------- |
| `toc.levels`               | `2..6`   | Include H2-H6 (skip H1 document title) |
| `toc.unorderedList.marker` | `-`      | Use `-` for list items                 |
| `toc.updateOnSave`         | `true`   | Auto-update on save                    |
| `toc.slugifyMode`          | `github` | GitHub-compatible anchor links         |

## Keyboard Shortcuts

### Text Formatting

| Shortcut           | Action               | Result         |
| ------------------ | -------------------- | -------------- |
| `Ctrl+B` / `Cmd+B` | Toggle bold          | `**text**`     |
| `Ctrl+I` / `Cmd+I` | Toggle italic        | `*text*`       |
| `Alt+S`            | Toggle strikethrough | `~~text~~`     |
| `Ctrl+M` / `Cmd+M` | Toggle math          | `$expression$` |

### List Management

| Shortcut                    | Action               |
| --------------------------- | -------------------- |
| `Tab`                       | Indent list item     |
| `Shift+Tab`                 | Un-indent list item  |
| `Alt+C`                     | Toggle task checkbox |
| `Backspace` (at line start) | Remove list marker   |

### Navigation

| Shortcut                       | Action                           |
| ------------------------------ | -------------------------------- |
| `Ctrl+Shift+]`                 | Increase heading level (H2 → H3) |
| `Ctrl+Shift+[`                 | Decrease heading level (H3 → H2) |
| `Ctrl+Shift+V` / `Cmd+Shift+V` | Open preview                     |

## List Editing

### Smart Indentation

Press `Tab` to indent a list item and `Shift+Tab` to un-indent:

```markdown
- First item
  - Nested item (Tab)
    - Further nested (Tab)
  - Back one level (Shift+Tab)
- Top level again (Shift+Tab)
```

The extension maintains proper list hierarchy automatically.

### Auto-Renumbering

Ordered lists auto-renumber when you add or remove items:

```markdown
1. First item
1. Second item (displays as 2.)
1. Third item (displays as 3.)
```

The workspace uses "one" style (`1.` for all items) which GitHub renders correctly.

### Task Lists

Create task lists with `- [ ]` syntax:

```markdown
- [ ] Incomplete task
- [x] Completed task
- [ ] Another task
```

**Toggle with `Alt+C`** - place cursor on a task line and press `Alt+C` to toggle the checkbox.

## Table Formatting

### Auto-Alignment

The extension automatically aligns GFM table columns when you save:

**Before save:**
```markdown
| Name           | Description                    | Status  |
| -------------- | ------------------------------ | ------- |
| Item 1         | Short                          | Active  |
| Long Item Name | A much longer description here | Pending |
```

**After save:**
```markdown
| Name           | Description                    | Status  |
| -------------- | ------------------------------ | ------- |
| Item 1         | Short                          | Active  |
| Long Item Name | A much longer description here | Pending |
```

### Table Syntax

Use standard GFM table syntax:

```markdown
| Left Aligned | Centre Aligned | Right Aligned |
| :----------- | :------------: | ------------: |
| Value        |     Value      |         Value |
```

Alignment indicators:
- `:---` - Left aligned (default)
- `:---:` - Centre aligned
- `---:` - Right aligned

## Math Support

For technical documentation, the extension supports LaTeX-style math expressions.

### Inline Math

Wrap expressions in single dollar signs:

```markdown
The equation $E = mc^2$ shows mass-energy equivalence.
```

### Block Math

Use double dollar signs for display math:

```markdown
$$
f(x) = \int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
$$
```

**Note:** Math rendering appears in the preview pane. GitHub may not render all math expressions.

## HTML Export

Export your markdown as a styled HTML file:

1. Open Command Palette: `Ctrl+Shift+P` / `Cmd+Shift+P`
2. Type "Markdown: Print current document to HTML"
3. Choose save location

The export includes:
- VS Code styling for consistent appearance
- Syntax highlighting for code blocks
- Rendered tables and lists

**Batch Export:**
Use "Markdown: Print documents to HTML" to export multiple files.

## Configuration Reference

The workspace settings (`.vscode/settings.json`) configure the extension:

```json
{
  // TOC Configuration
  "markdown.extension.toc.levels": "2..6",
  "markdown.extension.toc.unorderedList.marker": "-",
  "markdown.extension.toc.updateOnSave": true,
  "markdown.extension.toc.slugifyMode": "github",

  // List Configuration
  "markdown.extension.list.indentationSize": "adaptive",
  "markdown.extension.orderedList.marker": "one",
  "markdown.extension.orderedList.autoRenumber": true,

  // Formatting
  "markdown.extension.italic.indicator": "*",
  "markdown.extension.bold.indicator": "**",
  "markdown.extension.tableFormatter.enabled": true,

  // Editor
  "[markdown]": {
    "editor.formatOnSave": true,
    "editor.defaultFormatter": "yzhang.markdown-all-in-one"
  }
}
```

These settings are shared across the team via Git.

## Without the Extension

If you don't have the extension installed, everything still works:

| Feature    | With Extension       | Without Extension        |
| ---------- | -------------------- | ------------------------ |
| TOC        | Auto-updates on save | Manual updates needed    |
| Formatting | Keyboard shortcuts   | Type syntax manually     |
| Lists      | Smart indentation    | Manual indentation       |
| Tables     | Auto-alignment       | Manual alignment         |
| Tasks      | Toggle with Alt+C    | Edit `[ ]` manually      |
| Preview    | Enhanced preview     | Standard VS Code preview |

Agent-generated markdown is valid CommonMark/GFM and renders correctly everywhere.

## Troubleshooting

### TOC Not Updating

1. Ensure you've saved the file
2. Check `markdown.extension.toc.updateOnSave` is `true`
3. Verify the extension is installed and enabled

### Keyboard Shortcuts Not Working

1. Ensure the file is a `.md` file
2. Check for conflicting keybindings: `Ctrl+K Ctrl+S`
3. Try disabling other markdown extensions temporarily

### Tables Not Formatting

1. Ensure `markdown.extension.tableFormatter.enabled` is `true`
2. Check the table syntax is valid GFM
3. Save the file to trigger formatting

### Extension Not Detected

1. Reload VS Code: `Ctrl+Shift+P` → "Reload Window"
2. Reinstall the extension
3. Check Extensions view for errors

### Math Not Rendering

1. Math only renders in the preview pane, not the editor
2. Check syntax: `$inline$` or `$$block$$`
3. Some complex LaTeX may not be supported
