description: "[Learning] Review and apply prompt optimisations"
usage: /learning:optimise <command> [options]
---

Review and manage prompt optimisation proposals generated by the learning system.

**Commands:**

- `/learning:optimise status` - Show overall optimisation status
- `/learning:optimise analyse <agent>` - Analyse an agent's performance
- `/learning:optimise list` - List pending proposals
- `/learning:optimise review <proposal-id>` - Review a specific proposal
- `/learning:optimise apply <proposal-id>` - Apply a proposal
- `/learning:optimise reject <proposal-id> [reason]` - Reject a proposal
- `/learning:optimise rollback <agent>` - Rollback to previous version

**How Auto-Optimisation Works:**

1. **Data Collection**: Metrics and feedback are collected from all agent runs
2. **Analysis**: When enough data exists (50+ runs), patterns are identified
3. **Proposal Generation**: The optimiser agent suggests specific improvements
4. **Review**: You review the proposed changes
5. **Apply/Reject**: Apply improvements or reject with feedback

**Example Workflow:**

```
# Check status
/learning:optimise status

# Analyse a specific agent
/learning:optimise analyse backend

# List pending proposals
/learning:optimise list

# Review and apply
/learning:optimise review opt-20251221-backend
/learning:optimise apply opt-20251221-backend

# Or reject with reason
/learning:optimise reject opt-20251221-backend Too aggressive changes
```

**Arguments:**
$ARGUMENTS

---

Spawn the `dev-team:optimiser` agent to handle the optimisation request.

For simple status/list commands, run the optimiser-tool.py directly:
- `status`: `./plugins/optimiser-tool.py status`
- `list`: `./plugins/optimiser-tool.py list`
- `apply`: `./plugins/optimiser-tool.py apply <id>`
- `reject`: `./plugins/optimiser-tool.py reject <id> <reason>`
- `rollback`: `./plugins/optimiser-tool.py rollback <agent>`

For `analyse` commands, spawn the optimiser agent to do a thorough analysis and potentially generate a proposal.
